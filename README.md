# Курсы заочника

Учебная библиотека: 8 дисциплин и 3 организационных раздела.

Для каждого курса доступны вкладки «Задания» и «Тесты». Во вкладке заданий собраны условия, варианты, методички, шаблоны и материалы из презентаций. Тесты представлены только темами и доступными параметрами, без результатов и запуска.

HTML, документы и поиск работают без сервера: скачайте репозиторий и откройте `index.html`. Видеозаписи сохранены ссылками; исходный портал может запрашивать вход.

Публичная версия не содержит учётных данных, состояния личных ответов и ранее отправленных студенческих работ. Условия и учебные документы сохранены по материалам курсов от 26 октября 2026 года.
